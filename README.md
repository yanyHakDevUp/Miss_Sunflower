# Miss Sunflower 🌻

A 3D WebGL cinematic fan tribute and digital showcase dedicated to **CEO Lai Souyiek** and **Miss Sunflower Brand**.

## Features ✨
- **Realtime 3D Sunflower Bloom**: Procedural petal & seed geometry powered by Three.js WebGL engine.
- **Cinematic Sunrise Sequence**: GSAP animated bloom timeline with synthesized Web Audio soundtrack.
- **CEO Admiration Showcase**: High-resolution tribute highlighting Founder & CEO Lai Souyiek's Cambodian entrepreneurship.
- **Charity & Community Support (ជំនួយបរិច្ចាក)**: Dedicated featured tribute to CEO Lai Souyiek & her husband's charitable donations and community support in Cambodia.
- **Interactive 3D Studio**: 360° orbit, touch-pinch zoom, and dynamic time-of-day lighting presets (Sunrise, Noon, Golden Hour, Night).
- **Full Mobile Responsiveness**: Fully optimized portrait & landscape UI with responsive 3D camera FOV adjustments.

## Tech Stack 🛠️
- HTML5 / Vanilla CSS3 (Glassmorphism design system)
- JavaScript (ES Modules, Three.js, GSAP, Web Audio API)
- Vite

## Local Setup 🚀
```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
